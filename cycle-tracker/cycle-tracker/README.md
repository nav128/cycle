# מעקב מחזור - Cycle Tracker

אפליקציית Android לניטור מחזור הווסת באמצעות מעקב אחר טמפרטורת הגוף הבסיסית (BBT).

## תכונות

- **רישום קריאות טמפרטורה** - הוספת תאריך, שעה וטמפרטורה (2 ספרות אחרי הנקודה)
- **גרף טמפרטורה** - הצגה ויזואלית של טמפרטורת הגוף לאורך זמן
- **זיהוי שלבי מחזור** - זיהוי אוטומטי של:
  - שלב פוליקולרי (לפני הביוץ)
  - ביוץ (עלייה בטמפרטורה)
  - שלב לוטאלי (אחרי ביוץ)
- **ניתוח מבוסס נוסחה** - שימוש בכלל "3-מעל-6" לזיהוט ביוץ
- **אחסון מקומי** - כל הנתונים נשמרים באופן מקומי על המכשיר
- **ממשק עברית מלא** - כל האפליקציה בעברית עם תמיכה ב-RTL

## הנוסחה המדעית

האפליקציה משתמשת בכלל **"3-מעל-6"** (3-Over-6 Rule) לזיהוי ביוץ:

1. **קו בסיס (Coverline)** - מחושב מ-6 ימים עם הטמפרטורה הנמוכה ביותר
2. **זיהוי ביוץ** - מאושר כאשר:
   - 3 קריאות רצופות מעל קו הבסיס
   - הקריאה השלישית גבוהה ב-0.2°C לפחות מקו הבסיס

### שלבי המחזור

| שלב | טווח טמפרטורה | תיאור |
|-----|---------------|--------|
| פוליקולרי | 36.1-36.4°C | שלב לפני הביוץ - טמפרטורה נמוכה יחסית |
| ביוץ | עלייה חדה | עלייה של 0.2-0.5°C |
| לוטאלי | 36.5-37.0°C | שלב אחרי הביוץ - טמפרטורה גבוהה |

## דרישות מערכת

- Android 7.0 (API 24) ומעלה
- 10 MB שטח פנוי

## בניית האפליקציה

### דרישות מקדימות
- Android Studio Arctic Fox או גרסה חדשה יותר
- Android SDK
- JDK 8 או גבוה יותר

### שלבי בנייה

1. פתח את הפרויקט ב-Android Studio
2. ודא ש-`local.properties` מצביע על מיקום ה-SDK שלך
3. סנכרן את Gradle:
   ```
   File → Sync Project with Gradle Files
   ```
4. בנה APK:
   ```
   Build → Build Bundle(s) / APK(s) → Build APK(s)
   ```

### הרצה על מכשיר/אמולטור

1. חבר מכשיר Android או הפעל אמולטור
2. לחץ על כפתור Run ב-Android Studio
3. בחר את המכשיר היעד

## שימוש באפליקציה

1. **הוספת קריאה**:
   - לחץ על כפתור ה-➕
   - בחר תאריך (ברירת מחדל: היום)
   - בחר שעה (ברירת מחדל: כעת)
   - הזן טמפרטורה (לדוגמה: 36.45)
   - לחץ "שמור"

2. **צפייה בגרף**:
   - הגרף מציג את טמפרטורת הגוף לאורך זמן
   - ניתן לגעת ולהזיז את הגרף

3. **תובנות**:
   - האפליקציה תציג את שלב המחזור הנוכחי
   - תוצג קו הבסיס (Coverline)
   - התראות על זיהוי ביוץ

## פרטים טכניים

- **שפה**: Kotlin
- **ארכיטקטורה**: MVVM
- **בסיס נתונים**: Room (SQLite)
- **גרף**: MPAndroidChart
- **UI**: Material Design Components
